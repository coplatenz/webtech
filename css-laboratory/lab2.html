Question: Explain the difference between .card and #page-title. Answer: The .card is a class selector in CSS. It is used to apply the same style to multiple HTML elements that have the class name card.
The #page-title is an ID selector in CSS. It is used to style a specific HTML element with the ID page-title.
Difference: A class can be used on multiple elements, while an ID should be unique to one element on a webpage.
